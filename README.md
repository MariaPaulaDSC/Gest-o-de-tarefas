# Gest-o-de-tarefas
Site criado para a matéria de PW2, o site de gestão de tarefas vem para solucionar o maior e mais recorrente problema visto em diversas áreas da vida, é a gestão das próprias tarefas ou de terceiros, seja ela no trabalho, na escola ou até mesmo no dia a dia. Para isso criamos um site para solucionar este problema.
